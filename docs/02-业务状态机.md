# 业务状态机设计

## 1. 总流程

```text
用户上传票据
        ↓
AI 自动审核
        ↓
审核通过？
   ┌───────────┐
   ↓           ↓
通过         驳回/人工
 ↓             ↓
进入盲盒       结束/复核
 ↓
抽取消费券
 ↓
发放消费券
 ↓
用户查看券包
 ↓
商户核销
 ↓
发放积分
 ↓
积分兑换
```

## 2. 票据状态机 `ticket.status`

| 值 | 状态 | 说明 |
| --- | --- | --- |
| 0 | 待识别 | 已上传，待入队 |
| 1 | OCR 处理中 | OCR 任务执行中 |
| 2 | AI 审核中 | 多模态/风控评分中 |
| 3 | 审核通过 | 可进入盲盒 |
| 4 | 审核拒绝 | 终态 |
| 5 | 人工审核 | 中风险进入复核池 |
| 6 | 已兑换 | 已完成盲盒发券 |

### 流转

```text
待识别 → OCR处理中 → AI审核中
                      ├─ 审核通过 → 已兑换
                      ├─ 审核拒绝（终态）
                      └─ 人工审核 → 审核通过 / 审核拒绝
```

### 事件

| 事件 | 源状态 | 目标状态 |
| --- | --- | --- |
| `ticket.uploaded` | - | 待识别 |
| `ticket.ocr.started` | 待识别 | OCR 处理中 |
| `ticket.ocr.finished` | OCR 处理中 | AI 审核中 |
| `ticket.ai.approved` | AI 审核中 | 审核通过 |
| `ticket.ai.rejected` | AI 审核中 | 审核拒绝 |
| `ticket.ai.manual` | AI 审核中 | 人工审核 |
| `ticket.manual.approved` | 人工审核 | 审核通过 |
| `ticket.manual.rejected` | 人工审核 | 审核拒绝 |
| `ticket.exchanged` | 审核通过 | 已兑换 |

## 3. 消费券状态机 `user_coupon.status`

| 值 | 状态 |
| --- | --- |
| 0 | 待领取 |
| 1 | 已领取 |
| 2 | 已锁定 |
| 3 | 已使用 |
| 4 | 已过期 |
| 5 | 已撤销 |

### 流转

```text
待领取 → 已领取 → 已锁定 → 已使用
                 ↘ 已过期
                 ↘ 已撤销
```

### 核销约束

1. 仅 `已领取` 可锁定。
2. 仅 `已锁定` 可核销为 `已使用`。
3. 过期任务扫描将 `已领取/已锁定` 中过期券置为 `已过期`。
4. 同一 `coupon_code` 核销请求必须幂等。

## 4. 盲盒状态

### 4.1 盲盒配置

- `draft` 草稿
- `online` 上线
- `offline` 下线

### 4.2 开奖记录 `blind_box_open_log.result_status`

| 值 | 说明 |
| --- | --- |
| 0 | 谢谢参与 |
| 1 | 中奖已发券 |
| 2 | 中奖但库存失败（记日志，补偿/降级） |

## 5. 积分状态

积分不单独存“状态机对象”，以流水为准。

### 变更类型 `point_log.change_type`

| 类型 | 说明 |
| --- | --- |
| upload_ticket | 上传并通过审核 |
| checkin | 打卡 |
| use_coupon | 核销消费券 |
| invite | 邀请 |
| exchange | 积分兑换商品 |
| admin_adjust | 后台调整 |

### 流水约束

```text
before_points + change_points = after_points
```

用户余额更新与流水写入必须同事务。

## 6. 打卡状态 `checkin_record.verify_status`

| 值 | 状态 |
| --- | --- |
| 0 | 待验证 |
| 1 | 自动通过 |
| 2 | 待人工 |
| 3 | 通过 |
| 4 | 拒绝 |

### 验证方式 `verify_type`

- GPS
- WIFI
- BEACON
- PHOTO_MANUAL

一期默认：GPS 自动 + 抽检 PHOTO_MANUAL。

## 7. 商户入驻状态 `merchant.status`

| 值 | 状态 |
| --- | --- |
| 0 | 待审核 |
| 1 | 已通过 |
| 2 | 已驳回 |
| 3 | 已停用 |

仅 `已通过` 门店可核销。

## 8. 建议的领域事件

| 事件 | 触发方 | 消费方 |
| --- | --- | --- |
| `ticket.uploaded` | ticket-service | ocr-worker |
| `ticket.ocr.finished` | ocr-worker | ai-worker |
| `ticket.approved` | ai/risk | blindbox-worker |
| `coupon.issued` | coupon-service | message/point |
| `coupon.used` | coupon-service | statistics/point |
| `checkin.passed` | checkin-service | point-service |

状态机是后续规则扩展的边界。任何第三方平台接入，都不应破坏上述主状态流转。
