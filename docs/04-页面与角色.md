# 页面与角色设计

## 1. 消费者小程序（14 页）

| 编号 | 页面 | 核心内容 |
| --- | --- | --- |
| 01 | 首页 | Banner、上传入口、盲盒、热门券、打卡、积分 |
| 02 | 上传票据 | 拍照/相册、进度、提交 |
| 03 | AI 识别结果 | 提取字段、风险提示、审核状态 |
| 04 | 盲盒开奖 | 2~3 秒动效、结果、分享 |
| 05 | 我的卡券 | 未使用/已使用/已过期 |
| 06 | 卡券详情 | 规则、二维码、有效期 |
| 07 | 我的积分 | 余额、流水、等级 |
| 08 | 积分商城 | 商品列表 |
| 09 | 商品详情 | 兑换确认 |
| 10 | 打卡地图 | 附近点位、一键打卡 |
| 11 | 打卡详情/记录 | 历史与审核状态 |
| 12 | 消息中心 | 审核/发券/积分通知 |
| 13 | 我的 | 票据、卡券、积分、设置 |
| 14 | 设置/外链 | 大江网站等 |

### 盲盒动效建议

```text
礼盒抖动 → 发光 → 粒子 → 卡券翻转 → 展示结果
时长：2~3 秒
```

## 2. 商户小程序（8 页）

| 编号 | 页面 | 核心内容 |
| --- | --- | --- |
| 01 | 登录 | 账号/手机号登录 |
| 02 | 工作台 | 今日核销、快捷入口 |
| 03 | 扫码核销 | 摄像头/扫码枪 |
| 04 | 手工核销 | 验证码输入 |
| 05 | 核销记录 | 筛选、导出 |
| 06 | 门店管理 | 门店信息、营业状态 |
| 07 | 数据统计 | 日/周/月核销 |
| 08 | 设置 | 账号与通知 |

## 3. 管理后台（10 页）

| 编号 | 页面 | 核心内容 |
| --- | --- | --- |
| 01 | 仪表盘 | 发券、核销率、上传量、AI 通过率 |
| 02 | 用户管理 | 列表、黑名单、画像摘要 |
| 03 | 商户管理 | 入驻审核、门店、账号 |
| 04 | 票据审核 | 原图 + OCR + AI + 操作 |
| 05 | 消费券管理 | 模板、批次、规则 |
| 06 | 盲盒管理 | 概率、库存、开奖日志 |
| 07 | 积分管理 | 规则、流水、商城 |
| 08 | 活动中心 | Banner、任务、公告 |
| 09 | 风控中心 | 设备/IP/策略 |
| 10 | 系统设置 | 角色权限、配置项 |

## 4. 审核台信息架构

```text
┌──────────────────────┐
│      原始票据图片      │
├──────────────────────┤
│ 商户 / 金额 / 时间     │
│ 单号 / AI 评分         │
│ 风险原因               │
├──────────────────────┤
│   通过  |  拒绝  | 备注  │
└──────────────────────┘
```
