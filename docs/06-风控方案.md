# 风控方案

## 1. 目标

拦截：

- P 图 / 截图假票
- 重复上传刷券
- 定位作弊打卡
- 脚本批量注册与抽奖
- 商户重复核销

## 2. 票据三层校验

### 第一层 OCR

提取：商户名、金额、时间、单号。

### 第二层 多模态 AI

判断：是否真实票据、是否截图、是否疑似篡改。

### 第三层 业务唯一性

```sql
UNIQUE(order_no, amount, consume_time)
```

辅以图片 hash / 感知哈希近似查重。

## 3. 风险评分策略

| 分数 | 动作 |
| --- | --- |
| ≥ 85 | 自动通过 |
| 60 ~ 84 | 人工审核 |
| < 60 | 自动拒绝 |

## 4. 打卡防作弊

优先级：

1. GPS 距离（默认 300 米）
2. 可选 WiFi / Beacon（二期）
3. 随机照片抽检 + 人工

不要只靠用户上传照片。

## 5. 盲盒防刷

- 用户日限 / 活动总限
- 设备指纹与 IP 频控
- Redis 原子库存
- 开奖日志全量落库，支持回放审计

## 6. 核销防重

- `coupon_code` 唯一
- Redis 短锁 + DB 状态校验
- 已使用/已过期/已撤销直接失败
- 商户只能核销本店适用券

## 7. 黑名单维度

- 用户 ID
- 手机号
- openid
- device_id
- IP

命中策略可配置：拒绝上传 / 强制人工 / 禁止抽奖。

## 8. 上线门槛

| 风险项 | 指标 |
| --- | --- |
| 重复票据拦截 | ≥ 99% |
| P 图识别 | ≥ 85%（持续迭代） |
| 定位作弊 | ≤ 3% |
| 核销幂等 | 100% |
