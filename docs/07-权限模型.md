# 权限模型（RBAC）

## 1. 角色

| 角色 | 说明 |
| --- | --- |
| SUPER_ADMIN | 超级管理员 |
| CITY_ADMIN | 城市运营管理员 |
| OPERATOR | 运营人员 |
| AUDITOR | 票据审核员 |
| MERCHANT | 商户账号 |
| USER | 消费者 |

## 2. 菜单

```text
dashboard
user
merchant
ticket
coupon
blindbox
points

statistics

```

## 3. 权限点（示例）

```text
ticket:review
ticket:approve
ticket:reject
coupon:create
coupon:update
coupon:delete
blindbox:config
points:rule:update
merchant:audit
statistics:view
risk:blacklist:manage
system:role:manage
```

## 4. 数据权限

| 角色 | 数据范围 |
| --- | --- |
| SUPER_ADMIN | 全量 |
| CITY_ADMIN | 本市活动/商户/用户 |
| OPERATOR | 运营配置与统计 |
| AUDITOR | 审核队列与操作日志 |
| MERCHANT | 本商户/本门店核销数据 |
