# 部署方案

## 1. 开发环境

```text
本地 Docker Compose
- MySQL 8
- Redis
- RabbitMQ
- MinIO
```

## 2. 测试环境

```text
2C4G × 2
MySQL 主从（可先单机）
Redis 单机/哨兵
对象存储测试桶
```

## 3. 生产（10 万 DAU 目标）

```text
SLB / Nginx
  ↓
API Gateway / API Server × N
  ↓
Redis Cluster
MySQL 主从
MQ
OSS
AI 服务（可独立扩容）
```

## 4. 一期简化部署

不必一上来上完整 K8s 微服务。

建议：

1. 一个 API 服务
2. 一组异步 Worker（OCR/AI/过期/统计）
3. MySQL + Redis + MQ + OSS
4. 管理后台静态资源走 Nginx

## 5. 监控

- Prometheus + Grafana
- 业务指标：上传量、AI 通过率、重复票率、发券数、核销率、积分发放/消耗
- 基础指标：QPS、错误率、CPU、内存、队列积压

## 6. CI/CD

```text
Git Push → 测试 → 构建镜像 → 发布测试 → 灰度 → 生产
```
