# 研发排期（16 周参考）

| 阶段 | 周期 | 产出 |
| --- | ---: | --- |
| PRD 评审 | 1 周 | 范围冻结、优先级 |
| UI 设计 | 2 周 | 三端关键页面 |
| 数据库与接口 | 1 周 | DDL、OpenAPI |
| 小程序开发 | 4 周 | 消费者 + 商户核心流程 |
| 后台开发 | 4 周 | 审核、规则、统计 |
| AI 审核 | 2 周 | OCR + 评分 + 人工台 |
| 联调测试 | 1 周 | 闭环与压测 |
| 上线 | 1 周 | 灰度与监控 |

> 小程序与后台可并行，总日历可压缩到约 12~14 周，取决于团队配置。
