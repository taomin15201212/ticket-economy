# 实施计划（16 周 + Sprint 0/1）

> 状态：Sprint 0/1 已落地工程骨架与核心闭环可演示路径。  
> 技术栈：NestJS + TypeScript · MySQL 8 · Redis · RabbitMQ · MinIO · Vue3 三端。

## 1. 目标

把「设计资产包」推进到「可本地运行的工程骨架 + 主业务闭环 demo」：

```text
登录 → 上传票据 →（模拟）AI 审核通过 → 开盲盒发券 → 商户核销 → 积分入账
```

## 4. 主业务闭环（实现约定）

| 步骤 | API | 状态变化 |
| --- | --- | --- |
| 1 登录 | `POST /api/auth/login` | 创建/返回用户 + JWT |
| 2 上传 | `POST /api/ticket/upload` | ticket.status=0 |
| 3 提交 | `POST /api/ticket/submit` | 0→1→2→3（mock AI 默认通过） |
| 4 开盲盒 | `POST /api/blindbox/open` | 3→6，发 user_coupon，积分+ |
| 5 商户核销 | `POST /api/merchant/verify` | coupon 1→3，积分+ |
| 6 人工审 | `POST /api/admin/ticket/review` | 5→3/4 |

Mock AI 规则（可配置）：

- `AI_MOCK_MODE=auto_approve|auto_manual|auto_reject`
- 默认 `auto_approve`，便于本地演示闭环

## 6. 风险与裁剪

| 风险 | 应对 |
| --- | --- |
| 微信小程序资质/审核周期 | 先 H5 联调，并行申请 |

| 核销并发 | 乐观锁 version + request_id 幂等 |
